# 落霞洞天 08：统一照明基准

状态：已收到 `G:/mc/references/luoxia/08.png`，整座洞天的夜景照明层级、色温分区、道路引导和地下晶体光源已锁定。该文件作为宗门、古城、两处唯一居所、灵脉和 Boss 预留区的共同照明基准。

## 总体原则

- 洞天内不允许出现影响导航的大面积纯黑区域；玩家进入建筑、桥梁、洞窟和主路后，应始终能看见下一处灯光或地标。
- 照明分为“导航暖光、地标金光、环境冷光、事件强调光”四层，避免所有区域使用同一种亮度和颜色。
- 灯具优先成为建筑装饰的一部分：檐下灯笼、石灯、桥头灯、门楼灯、悬灯和晶簇发光面都要有明确位置。
- 以静态方块光源为主，粒子和动态效果只用于少量核心地标，控制区块和客户端负担。

## 四层照明体系

### 1. 导航暖光

使用暖橙或金黄色，覆盖主轴、桥面、台阶、城门、主街、矿洞主路和返回点。

- 地面主路：约每 `8..12` 格设置一个灯具或灯柱。
- 次路与回廊：约每 `12..16` 格设置一个灯具，转角和分叉额外补灯。
- 洞窟主下降路线：约每 `16..24` 格设置一个可见灯节点，桥头、门洞和安全平台加密。
- 建筑内部：入口、楼梯、走廊、主厅和工作台周围保持连续光带，避免玩家进入后看不清交互对象。

### 2. 地标金光

使用金白或高亮暖光突出中央宗门主殿、古城核心建筑、道胎主殿、金丹主炉和灵脉核心。地标金光应比普通导航灯亮一到两级，并从远处形成可辨认的方向提示。

### 3. 环境冷光

使用蓝白、青蓝和少量紫色，表现湖泊反光、瀑布、地下蓝晶、灵脉雾层、道胎星环和 Boss 场地的封印符印。冷光用于塑造空间深度，不取代主路线的暖光。

### 4. 事件强调光

由脚本按阶段启用，只作用于封印柱、传承阵心、Boss 中央法阵、灵脉核心或任务目标。未激活时使用低亮度待机光，激活后可切换为白金、赤金、紫色或冷蓝色，避免常驻高强度粒子。

## Minecraft 实现建议

- 檐下和墙体内部优先使用隐藏光源，再用灯笼、石灯、海晶灯、末地烛、蛙明灯或发光晶簇露出装饰面。
- 水景和地下区域使用海晶灯、蓝色晶体和水下光源，避免仅依靠火把破坏东方建筑风格。
- 金丹区域使用熔炉/岩浆的视觉火光配合隐藏光源，熔岩必须限制在炉膛和沟槽内。
- 道胎和 Boss 区使用白色、淡蓝色和金色光源，隐藏光源放在台阶、柱基和阵纹下方，保持圆环轮廓完整。
- 空中悬灯只在入口、主轴延长线、古城上空和高阶居所附近少量布置，避免满天灯实体造成性能和视觉噪声。
- 粒子效果只放在瀑布核心、灵脉核心、道胎主殿光环、金丹丹球和 Boss 阵心等少量节点。

## 夜间可读性验收

- 从落霞洞天入口能看见主轴上的连续灯光，以及中央宗门或远处核心地标的一处高亮轮廓。
- 古城主门、中央广场、主街和至少一条水岸路线在夜间清楚可辨。
- 道胎和金丹居所从远处能通过不同色温识别：道胎偏月白银蓝，金丹偏赤金炽白。
- 地下灵脉每层至少有一处安全平台和返回灯标；矿脉被挖走后，路线仍然保持照明。
- Boss 预留区未激活时有低亮度封印引导，激活后中央法阵和封印柱可以明显增强，但不让整个洞窟过曝。
- 所有建筑内部和桥梁入口都达到可导航亮度，且普通敌对怪不会在这些区域自然生成。

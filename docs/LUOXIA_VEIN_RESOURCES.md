## 采集与加工

矿石通常掉落 2 个对应原晶；时运有效，精准采集保留矿石。第 1–6 层矿石需要铁镐，第 7–9 层需要钻石镐。矿石提供少量经验。

晶簇具有四个实际生长阶段，形状随阶段变化。只有放在本层母岩上才会自然成熟，右键成熟晶簇收获一个原晶后回到幼生状态，立即重复点击不会产出。挖掘成熟晶簇有原晶掉落，精准采集得到的晶簇重新放置后从幼生开始。

六类设备共享五槽界面，槽位依次为原料、媒剂、燃料、产物、副产。显示加工进度和余热；红石供电时暂停，材料和余热保留。原料不足或产物、副产槽无法容纳完整结果时不消耗材料。换成另一种材料会重新计时，正常读档保留进度。

| 设备 | 加工与联动 |
| --- | --- |
| 原晶粉碎机 | 原晶 + 燧石 → 2 矿粉；盐岩 + 燧石 → 2 洗选盐 |
| 灵矿洗选机 | 原晶 + 洗选盐 → 2 精矿；露泉原晶 + 水桶 → 1 精矿并返还空桶 |
| 灵石凝结器 | 精矿 + 树脂 → 对应现有灵石，沿用现有修行系统 |
| 地火冶炼炉 | 富集铁、铜、金；地火原晶 + 煤 → 4 地火焦炭 |
| 灵泉蒸馏器 | 玻璃瓶 + 精矿 → 灵液；根髓岩 + 黏液球 → 树脂 |
| 封印充能台 | 空白钥匙 + 苍蓝／地火／地心精矿 → 对应钥匙 |

下品至上品灵石使用 2 精矿 + 1 树脂；极品灵石使用 4 精矿 + 2 树脂。普通熔炉也能以 1 原晶熔炼 1 精矿。9 个精矿可压缩成一块，再无损拆回。

地火焦炭提供 3200 tick 热量，可用于这些设备、原版熔炉和现有炼丹炉。露泉、苍蓝、地火精矿分别能替代现有回春丹、明目丹、避火丹的部分辅料。

露泉灵液恢复 8 点生命并短暂再生；地火灵液提供 2 分钟抗火；苍蓝灵液提供 2 分钟夜视。饮用沿用身份初始化检查，生存模式消耗灵液并返还玻璃瓶，创造模式保留物品。

## 自动化与机关

原版漏斗和 Forge `ITEM_HANDLER` 都可使用。加工设备顶部输入原料，侧面输入媒剂和燃料，底部提取产物和副产；燃料与媒剂会按配方分流。三个仓储方块均为真正的 27 格容器，支持任意方向漏斗、保存、破坏掉落和比较器。奖励仓不会自动补货。

封印门是单格门模块，可拼成更大的门阵。匹配钥匙能开关且不消耗；空白或错误钥匙不能开门。红石供电开门，断电关门；门内有实体时延迟关闭，避免卡住实体。开门后碰撞仅剩两侧门柱。自然生成的试炼房北门支持钥匙开关整扇门阵。普通共鸣台可切换 15 级红石输出；试炼房指定共鸣台则启动对应 Boss。

验矿台扫描周边 7×7×7 范围内已加载的专属矿石与晶簇，报告深度和矿点数，比较器输出矿点数（最多 15）。场域感应台在半径 8 格的包围盒内统计存活非玩家生物，输出对应比较器强度；每秒刷新。扫描不强制加载新区块。场域台用于门禁和战斗状态的基础联动，Boss 由试炼房指定共鸣台启动。

灯具可实际开关光照；休息座使用现有座椅实体，可坐下、下座和清理占用；勘测工作台打开原版 3×3 合成界面。支架、护盾柱、封印笼等承担结构和碰撞用途，目前不提供额外减伤或囚禁法术。

设备配方用 `xiuxian:vein_processing` 数据类型，可由数据包添加；现有 FTB Quests 后续可调用这些物品、采集和加工目标。暂不添加路标，也不要求安装第三方模组才能使用本批资源。

## 地下空间设计约束

1. 整个洞天地下按世界坐标划分九个高度带。每个新区块独立产生本区块内的矿层、洞窟和连接段；跨边界结构按确定性区域种子计算，保证分段接合。
2. 扩张由新区块生成驱动，避免每次进入洞天重新施工，也避免预先强制加载整片地图。深度资源丰富度和品阶递增，初始设计密度在地形阶段再实测调节。
3. 主矿井负责层间通行，外围资源网随探索无限延伸；纵向到本维度底部为止，Y=-64 基岩需要保留，地心层在其上生成可采集矿材。
4. Boss 房按较大的区域单元分布，区域边界及房间归属必须稳定，持久化通关状态，防止跨区块重复生成、重复奖励。地心主核心保持唯一，其外围地心矿脉可继续扩展。
5. 旧区块迁移采用明确的版本与范围记录，保护已经采集、建造或改动的区域。不得靠每次进入时清空地下来更新布局。

资源目录、`VeinLayers` 深度接口和 `data/xiuxian/vein/layers.json` 描述矿材分带；`VeinChunkGenerator`、`VeinTerrain` 与 `VeinEncounters` 已实现新区块地下生成和试炼。

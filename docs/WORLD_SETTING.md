# 世界观与修行体系（设计稿）

## 创作方向

本项目以《玄鉴仙族》的“五德、十二炁”和境界层级作为参考方向。游戏世界的历史、角色、家族、宗门、任务和文案由本项目原创，不直接搬用原作人物、段落或专有剧情。五德与十二炁用于建立世界的大势、传承和长期成长分支。

境界体系按目前查到的整理资料采用“胎息、炼气、筑基、紫府、金丹、道胎”顺序；筑基、紫府、金丹、道胎分别以道人、真人、真君、仙君为尊称，胎息阶段为六轮。细分规则仍要继续对照原作核验。五德与五行相关，十二炁属于另一组修行道途；其完整名目、规则和两套体系间的准确关系也待核实。本设计稿先确定模组需要的结构与玩法接口，不把未确认的细节写成原作设定。

## 世界背景提案

天地间的灵脉随五德流转而兴衰。数百年前，一次漫长的灵潮退落使许多古老传承断绝，仙门分崩，家族退守祖地，散修只能从遗迹与山野中寻找残存的功法。近年灵脉重新活跃，十二炁在各地显露征兆，旧道统留下的遗址相继开启。家族、宗门和散修因此重新踏上争夺灵脉、传承与机缘的道路。

玩家从凡俗出身开始。开局先选家族背景与修行身份，得到通用的《吐纳引气诀》，从胎息六轮开始修行，再通过打坐、丹药和探索逐步炼气。早期重点是活下来、积累修为、寻找传承；随着境界提升，逐步接触五德影响的地域与势力，并发现通往十二炁道途的线索。

这段历史是本模组的原创叙事提案，时间、事件和势力名称都可以在后续剧情设计时调整。

## 五德：世界气运与灵脉

模组暂按金、木、水、火、土五德组织世界层面的变化。五德不是五种可随意切换的元素技能，而是影响地域气运、灵脉状态、家族传承和资源特性的长期规则。

| 德 | 世界表现提案 | 可承载的玩法方向 |
| --- | --- | --- |
| 金德 | 整肃、坚固、肃杀、收敛 | 矿脉、锻造、守成传承、锐利术法 |
| 木德 | 生发、繁育、舒展、复苏 | 灵植、药性、恢复、持续成长 |
| 水德 | 流转、潜藏、润下、归藏 | 洞府水脉、隐匿探索、转化与蓄养 |
| 火德 | 显化、炼化、礼序、炽盛 | 炼丹、照见异象、爆发与传承仪式 |
| 土德 | 承载、聚合、稳定、养育 | 洞府根基、聚灵、护持和资源沉淀 |

五德之间的生克、轮替和盛衰应表现为世界事件或区域状态，不要求玩家一开始选定单一德性。四项角色资质不等同于五德选择；首版资质由家族出身和修行身份加权随机生成，先影响吐纳效率、承伤和突破消耗。

## 十二炁：高阶道途

十二炁先作为十二条彼此有别的修行道途来建模，而不是十二种普通矿物或十二个颜色。它们代表修士理解天地、凝聚道果和建立传承的不同方向。玩家早期使用通用功法积累基础修为；进入中期后通过遗迹、师承、家族典籍或特殊机缘接触一炁，之后才围绕该道途获取功法、材料和突破条件。

在核对原作细节前，十二炁的名字、编号、相互关系和对应境界暂不定案。每条道途未来至少需要定义：

- 稳定的数据 ID 与显示名。
- 核心修行理念，以及它与五德的关系。
- 可获得它的探索、师承或任务来源。
- 配套功法、灵材、丹药和突破条件。
- 对战斗、探索或生产带来的明确玩法差异。
- 未修习者能否使用相关物品，以及转修的代价。

五德与十二炁先视作不同层级的系统：五德描述天地与地域的气运变化，十二炁描述个体可追求的道途。未来可以存在相生、相斥或特定地域加成，但不强制构造“五德各自对应若干炁”的表格，待原作规则核实后再决定。

## 与现有原型的衔接

- 身份选择继续负责种族、家族出身和修行身份；首版只有人类，且开局直接获得入门功法。
- 胎息、炼气、筑基（道人）、紫府（真人）、金丹（真君）、道胎（仙君）作为当前境界原型；胎息设为六轮，其他细分先作为模组玩法参数。
- 灵根、根骨、悟性、气运按背景加权随机生成；分别影响吐纳收益、承伤减免、突破修为需求，以及吐纳收益。
- 境界进度增加玩家最大生命、攻击力和护甲；角色面板显示当前生效属性。
- 默认快捷键为 M 打坐、B 突破、K 打开档案，命令和物品栏档案入口继续保留。
- 凝气丹、灵材和灵矿将逐渐加入五德或十二炁标签，让采集、炼制、功法和境界进度彼此连接。
- 五德影响世界和资源生态；十二炁提供中后期的专精路线。丹药、打坐、任务、战斗和探索仍需保持多条有效成长路径。

## 当前境界成长参数

境界内的小阶段提供持续成长，大境界跨越则显著提升生命、攻击、真炁容量与承伤能力。修为门槛按境界序号的指数曲线增长，并对大境界冲关另加门槛倍率；具体经验值仍需通过单人流程继续校准。

小境界突破首版必成。大境界冲关的基础成功率与失败修为损耗如下，悟性、灵根、气运和功法的冲关代价还会微调成功率：

| 冲关 | 基础成功率 | 失败修为损耗 |
| --- | ---: | ---: |
| 胎息至炼气 | 90% | 20% |
| 炼气至筑基 | 60% | 30% |
| 筑基至紫府 | 28% | 40% |
| 紫府至金丹 | 12% | 50% |
| 金丹至道胎 | 5% | 60% |

离开打坐后，境界、阶段、根骨和当前功法共同影响气血恢复；真炁恢复则受境界、阶段、悟性和功法恢复能力影响。胎息阶段尚无额外的被动恢复，炼气后逐步加快。面板展示实际恢复间隔与每十秒真炁恢复量。未来的大境界突破还可以叠加雷劫、道劫或蒙昧之劫等独立挑战，本表只定义当前原型的冲关判定。

## 原作核对清单

在把名称和规则写进代码前，需要对照原作确认：

1. 五德与五行的准确关系、盛衰规则和各自代表的道途。
2. 十二炁的完整名称、分类及其与境界或道果的关系。
3. 五德和十二炁是否并列、包含、相生相克，或只在特定境界交汇。
4. 哪些内容属于小说明确设定，哪些只是读者整理或推测。

# 落霞洞天 07：Boss 预留区规格

状态：已收到 `G:/mc/references/luoxia/07.png`，Boss 预留区的入口、断桥、圆形战场、封印柱和返回路线已锁定。当前只规划空间和事件接口，不生成 Boss 本体、技能或掉落。

## 空间定位

Boss 预留区是落霞洞天内唯一的固定战斗场地，建议从 L9 洞天灵脉核心旁的封闭门进入。第一版可以作为灵脉底部的实体结构；后续若需要独立战斗副本，可复用相同结构标记切换到战斗维度或阶段空间。

- 结构必须从普通宗门、古城和随机洞窟生成池中排除。
- 世界内只存在一个预留区，首次生成后记录坐标和结构版本。
- 未激活前，场地保持安静，不自然生成普通敌对怪，也不提前生成 Boss。

## 固定空间结构

### 1. 封锁入口

灵脉核心或深层洞窟通往一座封印门，门前设置钥匙/任务触发位置和安全平台。门的两侧保留可读的符印、锁链、破损石柱和暖色引导灯，玩家能明确看出这里是后续路线，而不是普通矿洞。

### 2. 断桥接近段

入口到战场之间使用一段悬空石桥和不完整的断桥。断桥负责制造纵深和仪式感，但必须保留一条完整可走的主路线；缺口作为视觉元素或后续阶段机关，不让玩家因随机缺块无法抵达战场。

### 3. 圆形战斗平台

- 主战场为直径约 `64..96` 格的圆形或近圆形石台。
- 外环为可行走边界和封印柱基座，中环为环形走位带，内环为中央法阵。
- 中央法阵直径约 `16..24` 格，写入 `boss_center` 标记，预留 Boss 出场、阶段转换和战利品落点。
- 圆台边缘连接少量悬空岩柱和碎片平台，表现云海深度；关键战斗路线不依赖这些碎片平台。

### 4. 封印柱与锁链

沿外环均匀布置 `8` 或 `12` 根封印柱，每根写入独立编号标记。柱顶有圆形符印或灯盘，柱间用锁链和断裂石梁连接，供未来阶段机关启闭、护盾削弱或场地状态变化使用。

### 5. 远端天门与返回点

战场正对面保留一座高大的远端天门或传送门轮廓，用于 Boss 后续登场、阶段转场或剧情出口。入口侧另设固定返回点，战斗失败、撤退或事件取消时可以回到 L9 安全平台。

## 事件接口

预留以下结构标记，暂时只写入位置，不绑定具体内容：

- `boss_gate`：封印门与激活条件。
- `boss_approach`：断桥和战前安全区。
- `boss_center`：Boss 出场与中央法阵。
- `boss_ring_inner` / `boss_ring_outer`：两层走位和阶段边界。
- `boss_seal_0..11`：封印柱、锁链和阶段机关。
- `boss_exit`：撤退与战斗结束出口。
- `boss_reward_vault`：后续战利品房位置，只保留空房和门。

激活前不锁死玩家、不清空背包、不改变世界时间；这些行为由之后确定 Boss 机制时单独设计。

## 尺寸、材质和灯光

- 入口与接近段：约 `32..64` 格长，宽度保持 `5..9` 格，至少有一条连续主路。
- 战场平台：直径 `64..96` 格，外环和中央法阵之间保持足够走位空间。
- 主材：深板岩、黑石、灰白石和少量金色/银色封印装饰，形成与灵脉晶体和云海的对比。
- 封印光：封印柱使用白金或冷蓝光；中央法阵使用白金暖光；未激活时保持低亮度，激活时再由事件提高亮度或改变颜色。
- 边界安全：悬空边缘配置可见矮墙、柱基、链桥或能量屏障，避免玩家无意坠落；战斗机制需要封锁时由事件切换，不提前放置不可见墙体。
- 场地不能有大片黑暗；每个入口、柱基、桥头和环形分叉都有可见照明节点。

## 未来实现限制

- Boss 本体、阶段技能、召唤物、战斗伤害、掉落和成就全部留到后续设计确认。
- 不在本图决定 Boss 的种族、果位或故事身份，避免空间先绑定错误叙事。
- 预留区不参与普通建筑扩展、古城刷新或灵石矿脉再生成；战场下方和外围只保留景观岩体与事件通道。
- 普通敌对怪不会在预留区自然生成；所有守卫或 Boss 前置实体由激活事件显式召唤。

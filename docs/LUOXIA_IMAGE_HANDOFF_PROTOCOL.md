# 落霞洞天图片交付流程

目标：用少量图片锁定视觉和建筑结构，避免一次发送整套图片造成上下文膨胀，也避免在没有确认整体风格前先做大量蓝图。

## 推荐交付方式

优先把图片放到：

`G:\mc\references\luoxia\`

文件名按下面的编号命名即可，例如 `01_overview.png`、`02_sect.png`。然后在消息里只发送文件名或完整路径。我会直接读取本地图片，提取结构规格并写入设计文档；之后的讨论可以只引用这些规格，不必重复发送原图。

如果只能在聊天里上传：每条消息只发一张图，建议 JPG/PNG、长边 1024--1536 像素、尽量不超过 3 MB。不要发九宫格、视频、PSD 或同一建筑的十几个近似版本。

每张图附三句话就够：

1. 这张图属于哪个编号。
2. 哪些元素必须保留。
3. 哪些元素可以由我按 Minecraft 可建造性调整。

## 分阶段顺序

### 阶段一：统一视觉锚点

先交 `01_overview`：洞天整体鸟瞰图。它只需要表达地表、古城、悬空洞府、地下灵脉和整体色彩，不要求每座建筑都清楚。

确认后我会锁定：落霞宗的主色、石材/木材/金属组合、云海和丹霞的比例、地表到地下的层次、洞天总体尺度。

### 阶段二：两种可复制建筑

依次交 `02_sect` 和 `03_city`：

- `02_sect`：一组落霞宗门地面建筑，最好包含主殿、侧殿、回廊和灯具。
- `03_city`：一座修仙古城的鸟瞰或街区图，最好能看清城门、主街、坊区和夜间照明。

这两张决定随机生成模板池。图片不需要展示所有变体，一张代表图即可；我会从代表图拆分公共部件、变体部件和道路接口。

### 阶段三：唯一高修居所

依次交 `04_daotai`、`05_jindan`，每个只要一张最满意的图。先做道胎，再做金丹，因为道胎更适合确定洞天的最高视觉尺度。

这两类建筑会做成唯一坐标和唯一结构模板，不会放进普通随机池。图中最好能看出入口、主殿、修炼台、观景平台和可行走桥廊。

### 阶段四：地下、照明与 Boss 预留

依次交 `06_vein`、`07_boss`、`08_lighting`：

- `06_vein`：地下九层灵脉剖面，确定矿脉颜色、洞穴尺度和主脉位置。
- `07_boss`：只确定封锁门、战斗场地和进出路线，不需要 Boss 本体。
- `08_lighting`：如果前面的图已经把照明表达清楚，可以省略；否则补一张夜景/室内照明基准。

### 阶段五：实现

每确认一张，我会先把它转成一页结构规格：尺寸级别、入口方向、材质分组、灯具节点、可复制部件和禁止随机化的部件。全部确认后才开始实现独立维度、持久化随机布局、唯一居所、灵脉矿脉和 Boss 预留。

## 返工控制

- 每个阶段只保留一张“锁定图”；其他候选图不用继续发送。
- 如果要换风格，只替换当前阶段，不回头重做已锁定阶段，除非整体视觉锚点发生变化。
- 首先实现一块可玩的样板区，再扩展随机生成范围；这样可以先验证亮度、行走空间和建筑比例。
- 建筑图里出现的人物只当尺度参照，不转成实体或 NPC 设计。

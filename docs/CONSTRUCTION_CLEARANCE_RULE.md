# 建筑施工方块处理规则

每个建筑先将自己的完整施工范围清空，清完复扫，再写入建筑。清理范围包含楼宇之间和建筑上方，范围之外保持原样。

- 凡人城、金丹居所和道胎居所在各自占地内，从原点上一格清到世界高度上限；地基位置随后由建筑蓝图覆盖，更深地下保留。
- 清场自上而下执行；每个区块清理结束就退出本次循环，下次重新取区块及边界，防止漏扫。完整清场后再复扫一遍，随后开始建筑施工。
- 房间内部清理先于墙体、灯具和家具写入，避免相邻建筑相互清掉装饰。
- 落霞外部恢复整个既定施工体积的地形与空气写入；普通勘测遇到容器会暂停，营建令强制清场允许移除范围内容器及库存。
- 洞天古城清理完整城镇占地上方；洞天金丹和道胎主建筑清理自身占地，旧宫殿和旧阶梯使用独立清理体积，保留中间的其他宗门、古城、灵脉和 Boss 区。
- 施工范围内箱子、机器及库存全部移除；范围外保持原样。
- 城镇 v3/v4、金丹 v4/v5、道胎 v2/v3 和对应洞天道胎活动游标会重置为完整清场，再继续建造。已完成建筑不自动重建。

曾被旧版本清除的方块没有备份时无法据此恢复。

已完成但清场不完整的主世界验收建筑，可在创造模式且有管理员权限时执行 `/xiuxian town rebuild`、`/xiuxian jindan rebuild` 或 `/xiuxian daotai rebuild`。命令以各类型最近一座已完成建筑的原点重新排队完整清場、复扫和建造。

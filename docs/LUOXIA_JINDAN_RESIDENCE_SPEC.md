# 落霞洞天 05：金丹唯一居所规格

状态：已收到 `G:/mc/references/luoxia/05.png`，金丹居所的火脉位置、炼丹核心和唯一建筑规则已锁定。该结构只在落霞洞天出现一次，不进入普通宗门或古城随机模块池。

## 果位与视觉核心

金丹居所以“炉火凝丹、纯阳聚核、金乌曜日”为核心意象。建筑应像一座将火山灵脉炼成丹炉的天宫，强调集中、炽烈和秩序感，与道胎居所的星海、云水和月白色调形成对照。

- 主色：赤红、黑曜石、铜金、炽白和少量紫色灵焰。
- 主体形制：火山悬台、环形炉城、重檐金殿、丹炉群、熔岩沟槽和跨崖长桥。
- 关键符号：巨大金色丹球、中心炼丹炉、环形炉台、日轮、金乌或火凤纹样、紫色能量轨道。
- 视觉焦点必须是最高处主殿上方的金丹光球与中央丹炉；外围炉台和桥梁用于表现规模，不得遮挡核心。

## 固定空间结构

### 1. 焚天炉门与入场长桥

入口位于火山峡谷或深处山崖之间，由一座带铜金脊饰的高门和跨崖长桥组成。桥面需要有明确护栏、灯柱和安全落脚点，避免玩家一进入就被熔岩阻断。

### 2. 三重火环

- 外环：黑石悬台、丹材仓、火工院和少量观火亭，负责连接入口和主要生产区。
- 中环：环形丹炉台、炼器/炼丹辅助房、铜鼎阵列和紫色灵焰导管，形成连续的圆环动线。
- 内环：中央熔火井或主丹炉，周围为大型仪式台和固定阵心，作为金丹核心的逻辑区域。

环形平台使用固定桥梁和台阶连接；熔岩只出现在受控沟槽、炉膛或透明隔离槽中，不得随机漫出主要通路。

### 3. 金丹主殿

主殿位于环形平台后方或最高火山台地，采用赤金重檐、黑石台基、铜制门扉和高耸日轮。殿前布置两尊镇火兽或火纹柱，内部预留唯一高阶 NPC、丹道交互台和剧情触发位置。

### 4. 下层火脉与观火台

- 主炉下方保留一层可进入的火脉腔室，展示岩浆、熔岩柱、矿脉和热雾，但与玩家主路线隔开。
- 外环或侧翼设置观火台和断崖平台，能够看到整个环形炉城以及远处的火山群。
- 后方可预留一座封闭黑石洞门或断桥，作为未来 Boss、试炼或深层灵脉路线的入口；本阶段不放置 Boss 本体。

## 尺寸与坐标建议

- 唯一结构占地：约 `192 x 192` 到 `256 x 256`，包括外环平台、桥梁和火脉腔室。
- 建议位于洞天中低空的火山峡谷 `Y=80..150` 区域，与道胎高空环台保持明显垂直距离。
- 中央主炉直径建议 `25..35` 格，外环直径约 `120..170` 格；主殿高度高于普通炉台至少两层屋檐。
- 入口、中央主炉、主殿门和后方封锁洞门写入固定结构标记，供传送、任务和唯一 NPC 定位。

## 玩法与持久化规则

- 每个世界只生成一个金丹居所；首次生成后记录唯一坐标和结构版本，重进世界或重新加载区块不得复制。
- 金丹居所不参与普通宗门、古城和外围建筑的随机替换；周围保留开阔火山景观，确保金色丹球可以从远处看到。
- 普通敌对怪不在居所范围内自然生成；炼丹师、护炉者、试炼实体和剧情守卫由事件脚本按区域标记召唤。
- 外环生产区、内环主炉区、主殿区和下层火脉区分别设置逻辑标记，便于以后添加炼丹、传承、护炉和战斗事件。
- 不预先绑定 Boss 掉落或最终奖励，后方封锁洞门只负责保留路线和空间。

## Minecraft 建造基准

- 岩体：黑曜石、深板岩、玄武岩和深色石材构成火山台基；熔岩只在沟槽和炉膛内使用。
- 建筑：红色陶瓦/红砂岩、深色木构、铜块和金色饰件组成赤金宫殿。
- 炉火：熔炉、烟火、岩浆、海晶灯和隐藏光源分层布置；中央主炉亮度最高，外环逐渐降低。
- 紫色能量：紫水晶、紫色玻璃、末地烛或粒子效果仅作为导能轨道和阵心点缀，避免全场变成单一紫色。
- 安全：所有熔岩边缘配置矮墙、栏杆、透明隔离或明显警示结构，主路线保持连续可走。
- 结构优化：环形炉台、铜鼎、柱列和桥段使用可复用片段，避免大量独立装饰造成区块负担。

# 落霞洞天·九重云阙：内部维度设计稿

状态：等待建筑概念图确认后进入蓝图与世界生成实现。

## 设计结论

本项目当前确认建设的宗门是**落霞宗**。内部维度暂用工作名 **落霞洞天·九重云阙**，它是落霞外部山门上方入口所连接的独立洞天，不复用通用的太虚修炼维度。

这份设计把小说中常见的东方修仙建筑语汇、项目现有的落霞外部建筑风格，以及游戏中可持久化的随机地图规则结合起来。金丹、道胎的空间意象是面向游戏的原创扩展，待用户提供满意的生图后再定具体结构尺寸、材质和方块清单。

## 入口与总体尺度

- **外部入口**：落霞外部山巅可达平台附近，建议相对落霞建筑原点 `(+0, +135, -163)` 设置垂直天门/阵台。现有 `summit` 观测点在 `(+0, +134, -160)`，入口应贴近可行走平台，不使用远景最高峰。
- **维度标识**：建议独立使用 `xiuxian:luoxia_inner`，保留现有 `xiuxian:taixu` 的修炼、锚点、飞行和返回逻辑。
- **空间尺度**：首版有效探索区建议约 `2048 x 2048` 方块，地表基准约 `Y=96..128`，地下灵脉延伸到 `Y=-64`，上空保留 `Y=220..300` 的悬浮洞府层。
- **视觉轴线**：入口天门 -> 中央落霞宗门主轴 -> 云海中心 -> 地下主灵脉；高修居所位于上空和深层的独立轴线上，避免与普通建筑混成一片。
- **照明**：洞天不是黑暗地牢。地表环境光建议相当于柔和晚霞，宗门、古城、地下灵脉均使用分层灯光；所有可玩室内至少有连续的安全照明节点。

## 三类建筑与刷新规则

### 1. 落霞宗门建筑群：地面、多处、可复制

这是洞天最常见的人工建筑类型，保留外部落霞宗的赤霞、暖石、青铜、朱红木构和层叠飞檐，但规模和功能比外部山门更丰富。

建议模块：山门分舵、讲经殿、藏经阁、丹房、炼器台、演武台、药园、灵兽圃、钟楼、观星台、弟子院、执事院、渡云廊桥、瀑布水榭、灵田和小型传送台。

建议规则：

- 以 `192 x 192` 或 `256 x 256` 的探索网格定位。
- 每个网格约 `25%..35%` 的概率出现一个宗门建筑组合；组合内部从模块池抽取，保证道路和水系连通。
- 初始洞天建议生成 `8..14` 处，远期通过探索区扩展到 `20..30` 处。
- 同一模块在外观上允许重复，但主殿、钟楼和阵台使用三到五种变体，避免整张地图复制粘贴。
- 不生成普通敌对怪。宗门内的守卫、执事、Boss 或剧情 NPC 只由结构触发或事件脚本召唤。

### 2. 高修居所：唯一、震撼、对应果位

高修居所不能按普通建筑刷出。每个果位只保留一个固定地点，第一次生成后把坐标和版本写入洞天存档，之后不会因重进世界或区块重载改变。

**道胎境唯一居所：九天道胎宫**

- 位置：上空灵脉瀑布源头，建议处在地表上方 `Y=220..280` 的孤立悬空天台。
- 意象：初生道果、太初混沌、阴阳初分、星河与九重玉环。
- 空间：外环天门、悬空长阶、道胎主殿、悟道台、无风灵泉、环形星图阵；四周只保留云海、瀑布和远山，不出现凡人街市杂物。
- 游戏用途：后期高阶 NPC、道胎试炼、唯一性任务线和高阶 Boss 房入口的前置地标。

**金丹境唯一居所：赤金丹阙**

- 位置：中央山脉深处或高温丹霞山巅，建议处在 `Y=80..150` 的熔金云海上方。
- 意象：金丹如日、炉火、紫气、九鼎和圆满凝聚。
- 空间：九鼎丹炉殿、环形丹台、赤金琉璃屋脊、紫气回廊、护山阵柱、炼丹火池；动线要能让玩家实际走入主殿和观景平台。
- 游戏用途：金丹级人物、丹道剧情、后期材料与 Boss 房的第二层门槛。

后续若加入元婴或更高果位，沿用“每一果位一处唯一居所”的规则，不把高修宅邸加入普通随机池。

### 3. 凡人修仙古城：地面、多处、宏大

古城是洞天中最有生活感的区域，规模应明显大于普通村镇，同时让修仙元素融入城市功能，而不是把所有房屋都做成宫殿。

建议模块：九门城墙、主街、坊区、河渠和拱桥、牌坊、药铺、铸器铺、客栈、茶楼、书院、灵米仓、城隍台、飞舟/传送广场、夜间灯市和城外驿道。

建议规则：

- 以 `384 x 384` 或 `512 x 512` 的网格定位。
- 每个网格约 `8%..12%` 的概率出现一座完整古城，外围可以生成零散驿站和小坊市。
- 首版建议 `2..4` 座主城、`6..12` 个小坊市，城市之间用山道、河渠、渡云桥或古驿路连接。
- 古城白天有自然光，夜间以灵灯、灯笼、店铺窗火和桥下水灯组成连续照明；不依赖大量火把堆放。
- 城内不生成普通敌对怪；市民、商贩、修士和事件实体使用脚本或结构触发。

## 洞天分层与 Boss 预留

1. **天门层**：落霞外部入口、接引台、返程阵门、地图总览和安全落脚点。
2. **宗门地表层**：中央落霞宗门主轴、分舵、灵田、药园、演武场和自然景观。
3. **古城地表层**：主城、坊市、河渠、商路和凡人生活区，分布在中央轴线外围。
4. **云海悬空层**：道胎居所、观星台、浮空灵岛和远景山海，控制可见度和稀有资源叙事。
5. **地下灵脉层**：九层渐深矿洞。上层是可探索的灵泉和支脉，中层是灵石矿廊，下层是主脉、晶壁和锁定区域。
6. **归墟禁区**：预留一处唯一 Boss 房，不提前刷普通建筑和实体。入口采用封闭阵门、断桥或九重锁链，后续由剧情/钥匙/击破条件解锁。

Boss 房的中心位置和房间尺寸先固定在地图布局数据中，视觉上可以先做“封锁门”和“远景轮廓”，不把 Boss 本体、战利品和刷怪逻辑提前写死。

## 灵脉与灵石矿脉

灵脉是洞天的核心资源层，生成应该由深度、主脉距离和区域类型共同决定，而不是只把外部矿石数量简单乘倍数。

建议首版相对外部世界的放大规则：

| 品质 | 洞天建议 | 主要深度 | 设计目的 |
| --- | ---: | --- | --- |
| 普通灵石 | 每区块约 12 个矿脉起点 | `Y=-48..64` | 地表、古城和宗门日常资源 |
| 中品灵石 | 每区块约 6..8 个矿脉起点 | `Y=-56..32` | 支脉和地下灵泉附近 |
| 上品灵石 | 每区块约 3..4 个矿脉起点，约 1/3 区块实际出现 | `Y=-64..8` | 主脉外围和高修居所下方 |
| 极品灵石 | 每区块约 2..3 个矿脉起点，约 1/6..1/8 区块实际出现 | `Y=-64..-32` | 九层主脉和 Boss 预留区周围 |

主灵脉节点使用固定的世界种子和洞天布局种子生成，建议至少设置中央主脉、环形副脉和两条通往高修居所的支脉。矿脉视觉上应有蓝白、青金和赤金三种发光层次，避免所有矿石都只是贴在普通石头上的彩色方块。

## 生图统一要求

所有图片都请优先生成：

- 建筑概念设计，不要游戏截图，不要 UI，不要文字、水印、Logo。
- 正交/等距鸟瞰图 + 正立面/剖面图；保持同一组图片的材质、比例和色彩一致。
- 画面标出清晰的入口、主要动线、平台、桥、门和可站立区域，但不要用文字标注。
- 建筑结构要能拆成 Minecraft 方块结构：清楚的柱网、台阶、屋顶、墙体、窗洞、灯具和可重复模块。
- 人物只作为极少量尺度参照，不能成为主体；高修居所图最好无人。

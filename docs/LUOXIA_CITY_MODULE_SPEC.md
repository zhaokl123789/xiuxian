## 已锁定的城市特征

- 古城是大型封闭式城市，外围有连续城墙、城楼、角楼和护城水系；主城门位于正面或主轴端点。
- 城内存在一条宽阔中央主街，从主城门穿过坊市，通向后方高台上的府邸、宗祠或城市核心建筑。
- 城区由密集街坊、十字巷道、桥梁和水道组成；水道可穿过城内并连接外围湖泊，形成水上交通和夜景倒影。
- 城市建筑以两到三层的木石楼、商铺、客栈、茶楼和民居为主，核心地标才使用高层楼阁或塔楼。
- 夜景是重要识别点：屋檐灯、街灯、河灯、桥头灯和城墙灯形成连续暖光；街区内部不能出现大面积黑暗。
- 东方修仙元素以牌楼、阵台、观星台、药铺、灵材商行、炼器坊和飞舟/渡口等公共设施体现，数量要克制，保持“凡人城市”主体。
- 右侧辅助图中的蓝色法阵或高台可作为少量城市公共传送/祭祀设施，不能让每个街坊都出现大型法阵。

## 固定与随机部分

### 每座古城固定生成

- 一圈可通行的城墙、至少一座主城门和若干侧门。
- 一条从主城门进入的中央主街。
- 一处中央广场或主市集，作为玩家辨认城市中心的锚点。
- 至少一条主水道或护城河，以及连接道路的桥梁。
- `2..4` 个大型地标：府邸、城隍/宗祠、观星台、塔楼、渡口或公共阵台中择取。

### 可随机抽取的街坊模块

1. 住宅坊：连续院落、窄巷、内向式天井和小型祠堂。
2. 坊市街：灵米、布匹、符箓、药材和日用修炼物资商铺。
3. 客栈与茶楼：临街店面、二层回廊、后院和灯笼密集的入口。
4. 药铺与灵材行：柜台、药柜、晾晒架、仓房和小型水井。
5. 炼器坊与铁匠铺：炉台、烟囱、堆料区和隔热院落。
6. 水岸街区：码头、游船、河灯、临水楼和跨河小桥。
7. 粮仓/商会/货栈：较大封闭院落，连接主路或水路。
8. 塔楼与观景台：少量竖向地标，用于远景识别和高差连接。
9. 公共阵台：圆形或八角形石台，配少量蓝色灵光，仅作为城市公共设施。
10. 城墙节点：角楼、箭楼、城门瓮城和登墙楼梯。

## 初始生成参数

- 单座古城占地：约 `384 x 384` 到 `512 x 512`。
- 单个洞天内古城出现概率：约 `8%..12%` 的合适地表区域；生成后位置持久化，不因重进世界重新排列。
- 每座古城初始包含 `2..4` 个大型地标、`6..12` 个街坊和若干连接道路/水道模块。
- 街区建筑可重复，但主城门、中央广场、城市核心地标和主桥不重复堆叠。
- 古城之间允许共享模块库，但通过城墙形状、河道走向、中心地标和屋顶组合产生差异。

## 材质、灯光和生活感

- 城墙与桥基：灰白石、深色石基和少量砖色装饰，突出厚重和防御感。
- 民居与商铺：深木、灰瓦、朱色门窗、暖色纸灯和少量铜件；屋檐高度以两到三层为主。
- 核心建筑：可使用更高的重檐楼阁、金色脊饰和石阶，但视觉等级低于道胎、金丹唯一居所。
- 水景：蓝黑夜水、桥下灯影、河灯和小型码头；水道必须有可行走的岸线或桥梁。
- 照明：城门、主街、广场、桥头、商铺招牌和城墙灯连续布置；保留少量较暗的后巷作为氛围变化，但不能影响导航。
- 生活装饰：招幌、货架、药柜、炉台、酒旗、木箱、船只和石井，优先放在模块内部，减少道路阻塞。

## 结构连接规则

- 主街建议 `9..13` 格宽，次街 `5..7` 格宽，小巷 `3..5` 格宽；主街和水道交叉处必须生成桥或沿岸平台。
- 城门到中央广场保持至少一条连续可走路线；随机街坊不能堵死主街、主桥或主要水道。
- 城墙内侧预留巡墙通道和登墙楼梯；城墙外侧保留护城水面、坡岸或林地缓冲带。
- 生成水岸模块时，建筑入口必须朝向道路或码头，避免整片房屋背对所有可行走路径。
- 普通敌对怪不在古城建筑范围内自然生成；居民、商贩、护卫和剧情实体由结构标记或事件系统触发。

## 与其他区域的边界

- 古城可与洞天湖泊、主河流和外围道路相连，但不直接复制宗门主轴。
- 古城中心可以出现公共法阵、观星台或修士管理府，但不生成道胎、金丹级唯一居所。
- 高修居所、地下灵脉和 Boss 房交给后续专用模板。

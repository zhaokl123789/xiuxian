## 已锁定的总体关系

- 洞天以大型山水盆地为主体，中心是湖泊、岛屿、瀑布和层叠山崖组成的核心景观。
- 从入口方向进入后，有一条明确的中轴通向中央宗门核心；中轴经过门楼、长桥、台阶和连续院落，承担玩家的第一条主路线。
- 中央区域建筑密度最高，外围逐渐过渡到孤峰、飞瀑、云海和零散悬空岛，形成“中心繁盛、边缘险峻”的空间层次。
- 远景存在成组的高耸门柱、塔状山峰和悬空石岛。它们用于建立洞天尺度，不作为普通可复制住宅。
- 主视觉为落霞时分：朱红屋檐、深色石木、金色边饰、秋红林木、青蓝水面、暖橙夕光和乳白云海。
- 建筑整体采用东方修仙宗门语汇：重檐、牌楼、长桥、层台、围墙和依山院落；装饰密度集中在中轴和核心宗门区域。
- 下方辅助图显示了蓝色与金色发光的地下洞窟，以及带核心空腔的分层剖面。它们可作为后续灵脉层的气氛基准，具体矿脉结构留到 `06_vein` 再锁定。

## 第一版灰盒比例

这些是建造比例，不是对图片像素的硬测量，后续可根据游戏动线微调：

- 总体地表活动区：约 `2048 x 2048` 方形范围。
- 湖泊、主岛和核心山水区：约占总体平面 `60%..70%`。
- 中央宗门核心及中轴院落：约占总体平面 `20%..25%`，位于主视线尽端。
- 入口至中央核心的主轴宽度：约占总体宽度 `8%..12%`，保持远距离可辨识。
- 外围悬空岛和孤峰：分布在核心区外缘，作为远景和支路落点，避免把整个边界做成连续城墙。
- 地表主体维持在概念稿的 `Y=96..128` 带；高峰、门柱和悬空景观可上探到 `Y=220..300`；地下灵脉预留至 `Y=-64`。

## Minecraft 灰盒映射

- 山体与崖壁：深色石材、凝灰岩、安山岩和少量发光晶簇，保留大块垂直断面。
- 落霞建筑：深色木材、红色陶瓦/红砂岩、铜和少量金色点缀，屋檐轮廓优先于细碎装饰。
- 水体与云海：青蓝水面、白色雾层和瀑布；主轴桥面需要保持清晰的碰撞和导航宽度。
- 夜间照明：沿主轴、桥头、门楼、宗门核心和城市入口布置分层灯光。灯光方案仍以 `08_lighting` 为最终基准。
- 入口第一视野必须能同时看见主轴、中央核心和至少一处高耸山体，避免玩家进入后只看到近距离墙面。

## 玩法与生成约束

- 入口、主轴和中央宗门核心是固定地标；普通宗门模块和古城模块在外围地表区域随机布置。
- 外围随机建筑不能遮挡主轴远景，也不能堵住入口到核心的连续路线。
- 高修唯一居所应放在高峰、悬空台地或远离主轴的显著位置；具体位置和造型等 `04_daotai`、`05_jindan`。
- 地下矿脉、Boss 区和具体刷怪规则不在本张图中定稿。

# 落霞洞天 04：道胎唯一居所规格

状态：已收到 `G:/mc/references/luoxia/04.png`，道胎居所的果位意象、空间层级和唯一地标规则已锁定。该结构只在落霞洞天出现一次，不进入普通宗门或古城随机模块池。

## 果位与视觉核心

道胎居所以“天道初成、星海孕育、阴阳归一”为核心意象。整体应让玩家感觉进入了高于普通宗门建筑的天上道场，而不是一座放大的住宅。

- 主色：月白、银蓝、淡金和少量青玉色；允许使用深蓝夜空作为背景对比。
- 主体形制：白石悬空台、细长金色立柱、环形拱桥、重檐天宫和高处的圆环光门。
- 关键符号：星轨、日月环、天体圆盘、太极/阴阳水池、环形阵纹、云海瀑布和少量鱼形或灵兽浮雕。
- 视觉焦点必须是最高处的道胎主殿与其背后的巨大光环，外围环台用于衬托中心，不得抢走主殿的层级。

## 固定空间结构

### 1. 迎天长桥

从下方云海或高峰方向进入，使用一条清晰的白石长桥连接第一座圆形台地。长桥两侧设置低矮护栏、金色灯柱和少量浮云间隙，确保入口方向容易辨认。

### 2. 三重环台

- 外环：较低的环形步道与若干小型悬空庭院，负责远景轮廓和环形动线。
- 中环：星象台、观云台、静修亭和环形水渠，设置可交互的阵纹节点。
- 内环：主殿前的大型圆台，中心可以布置太极水池或发光道纹，作为仪式和剧情空间。

环台之间使用固定桥梁或阶梯连接，不使用随机拼接；每一层至少保留一条返回主轴的安全路线。

### 3. 道胎主殿

主殿位于最高台地后方，采用多重屋檐、白石台基、金色脊饰和深蓝内檐。正门前保留宽阔台阶、两侧高柱与圆环光门，内部预留唯一高阶 NPC、修炼台和剧情触发位置。

### 4. 天象与水景节点

- 主殿周围布置星轨圆盘、日月符号和少量悬浮晶体。
- 环台边缘生成瀑布、云海和悬空岩柱，瀑布向下延伸到云层，但不把关键道路变成无法通过的水幕。
- 中环或内环保留一个可站立的圆形阵心，供后续任务、传承或战斗前置使用。

## 尺寸与坐标建议

- 唯一结构占地：约 `192 x 192` 到 `256 x 256`，包含外围浮岛与桥梁。
- 建议位于洞天高空层 `Y=220..300` 的独立高台或瀑布源头附近，避开古城和普通宗门生成区。
- 结构最高点为主殿光环，最低点为外环浮岛；上下层之间保留至少 `24` 格垂直间距，突出悬空感。
- 入口、中心阵心和主殿门口写入固定结构标记，供传送、任务和唯一 NPC 定位。

## 玩法与持久化规则

- 每个世界只生成一个道胎居所；首次生成后记录唯一坐标和结构版本，重进世界或重新加载区块不得复制。
- 允许玩家从外部远望，但不让普通随机建筑贴靠环台，保持完整的天宫轮廓。
- 普通敌对怪不在居所范围内自然生成；高阶 NPC、试炼实体和剧情守卫由事件脚本按区域标记召唤。
- 主殿、内环阵心和外环观景台分别作为三个逻辑区域，方便以后添加对话、传承、试炼和战斗前置。
- 暂不放置 Boss 本体和最终掉落；可在主殿后方或下层断桥处预留后续剧情通道。

## Minecraft 建造基准

- 台基：石英/方解石/白色石材与深色石材少量搭配，避免整片纯白导致轮廓丢失。
- 金色细节：铜、黄铜色装饰或金块只用于脊饰、柱头、灯座和阵纹边框。
- 发光：海晶灯、末地烛、淡色灯笼、发光晶簇和隐藏光源分层布置；主殿和阵心亮度最高，外环略低。
- 护栏：低墙、栏杆和金属柱连续布置，避免悬空平台产生误坠路线。
- 结构优化：重复使用圆环、桥梁和柱列模板，减少大量独立方块造成的区块负担。

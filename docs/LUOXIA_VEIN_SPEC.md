# 落霞洞天 06：地下灵脉与灵石矿脉规格

状态：已收到 `G:/mc/references/luoxia/06.png`，地下纵向层次、晶体色带、主下降路线和底部灵脉核心已锁定。图片显示的是四个主要视觉色带；游戏实现拆成九个逻辑层，以便控制矿脉品质、探索节奏和区块性能。

## 总体结构

地下灵脉从地表宗门和古城下方向下展开，采用中心螺旋/瀑布式下降路线，外围分出桥梁、洞厅和矿脉支洞。越往下，洞窟越大、晶体越纯、照明越集中，最底部是唯一的洞天灵脉核心。

- 地表过渡：山体裂隙、井台、瀑布后洞门和宗门/古城边缘入口。
- 水雾蓝晶带：蓝白晶簇、地下水、瀑布、雾层和小型悬桥。
- 深蓝晶洞带：大块蓝色灵石、宽阔洞厅、断桥和环形观景台。
- 赤金火脉带：红色、橙色和金色晶簇，受控熔岩沟槽与热雾。
- 底部核心带：巨大金色灵脉晶核、环形平台、封闭门和通往更深处的预留空间。

## 九层逻辑分区

逻辑层以探索和资源品质区分，不要求每层都成为完全独立的平面：

| 层级 | 主要环境 | 资源定位 | 玩法重点 |
| --- | --- | --- | --- |
| L1 | 地表裂隙、浅井、石桥 | 普通灵石 | 入口、教学和安全回路 |
| L2 | 水雾洞、浅瀑布、蓝白晶簇 | 普通/少量上品 | 水路、观景台和支洞 |
| L3 | 蓝色石钟乳洞 | 上品灵石 | 宽洞探索和桥梁路线 |
| L4 | 深蓝晶洞、地下湖 | 上品/少量极品 | 大型晶簇和分叉路线 |
| L5 | 蓝红交界、热雾裂谷 | 上品/极品 | 温度变化、断桥和受控火槽 |
| L6 | 赤色火脉层 | 极品灵石 | 火脉支洞、丹材和守卫事件 |
| L7 | 金红熔岩层 | 极品/洞天高品 | 高风险采掘和封闭矿厅 |
| L8 | 金色晶簇深层 | 高品灵石、灵髓 | 复杂桥网和剧情门 |
| L9 | 洞天灵脉核心 | 核心晶髓，数量受控 | 唯一核心、传承和 Boss 路线预留 |

建议地形高度从地表 `Y=96..128` 逐步下降到 `Y=-64`；L1-L2 主要位于 `Y=64..96`，L3-L5 位于 `Y=16..64`，L6-L8 位于 `Y=-32..16`，L9 位于 `Y=-64..-32`。实际洞厅可以跨越相邻高度，避免层层整齐切片。

## 灵石矿脉生成规则

灵石矿脉使用洞天专属生成规则，不直接套用外部世界的 `#minecraft:is_overworld` 生物群系修饰器。矿脉锚点写入区块持久化数据，首次生成后保持不变。

以一个约 `256 x 256` 的地下勘探区为基准：

- 普通灵石：约 `12..16` 个矿脉簇，主要位于 L1-L3，用于日常采集。
- 上品灵石：约 `6..8` 个矿脉簇，主要位于 L3-L5，数量明显高于外部世界。
- 极品灵石：约 `3..4` 个候选矿脉簇，约三分之一实际形成完整矿脉，主要位于 L5-L7。
- 洞天高品灵石：约 `2..3` 个候选点，约六分之一至八分之一实际形成，主要位于 L7-L8。
- 洞天灵髓：L9 核心周围设置少量固定环带，数量受控，不生成无限重复矿簇。

矿脉优先沿洞壁、晶簇根部、瀑布后方、熔岩沟槽边缘和桥下岩层生成；不得直接堵塞主路线、门洞、楼梯、桥面或剧情门。

## 探索路线与安全规则

- 主下降路线采用一条可回溯的螺旋桥/瀑布阶梯，从地表入口贯穿到 L8；L9 核心入口由固定门或封锁桥控制。
- 每个逻辑层至少设置一个安全平台、一个照明节点和一个返回上层的标记点。
- 支洞可以生成断桥、窄台和矿厅，但必须保留可识别的回路，避免玩家挖穿后迷失方向。
- 水流和熔岩只在预定槽道内生成，采用石墙、栏杆或透明隔离保护主路。
- L9 核心周围预留 Boss 或传承战斗空间，不提前绑定 Boss 本体、掉落和触发条件。

## 晶体与照明基准

- L1-L2：白蓝晶簇、浅色灯笼和瀑布反光，亮度柔和但不能出现全黑区域。
- L3-L4：深蓝大型晶簇、海晶灯和冷色隐藏光源，突出洞窟纵深。
- L5-L6：红橙晶簇、熔炉光和少量紫色导能线，形成火脉过渡。
- L7-L8：金色晶簇、暖色灯柱和岩浆反光，亮度集中在矿厅与桥头。
- L9：巨大金色晶核、环形阵纹和稳定暖光，作为整个地下系统的视觉终点。

每隔约 `16..24` 格设置一个可见照明节点；重要分叉、门洞、桥头和矿厅入口额外加灯。光源不能只依靠矿石发光，避免矿脉被挖走后路线变黑。

## 生物与性能约束

- 落霞洞天地下灵脉不自然生成普通敌对怪；矿脉守卫、试炼实体和 Boss 前置事件由结构标记或脚本触发。
- 洞厅和桥梁优先由有限尺寸的模块拼接，避免无限递归洞穴和不可控区块生成。
- 蓝晶、红晶、金晶使用可复用的簇状结构；瀑布、雾层和粒子效果只在主要景观节点启用。
- L9 灵脉核心和已生成矿脉写入版本号，后续升级只能增量补充，不重排玩家已经探索的地下结构。

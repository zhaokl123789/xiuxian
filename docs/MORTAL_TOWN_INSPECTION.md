# 凡人城镇施工与自制方块验收

城镇继续作为独立验收建筑，尚未接入洞天探索刷新。新生成的城镇使用本模组原创的东方模型和纹理，不需要长生诀、GeckoLib、Patchouli 或 TerraBlender。

## 生成和施工

创造模式获得验收道具：

```mcfunction
/give @s xiuxian:mortal_town_inspection_token
```

右键方块，以被点击方块的高度为地基顶面；空气右键，以玩家脚下一格为原点。也可以使用：

```mcfunction
/xiuxian town generate
/xiuxian town generate <x> <y> <z>
/xiuxian town status
/xiuxian town cancel
/xiuxian town rebuild
```

验收只允许在主世界进行。建筑总占地东西 345 格、南北 257 格，包含城外住宅和屋檐。整个占地内从原点上一格到世界高度上限全部清空，箱子、机器及库存一并移除。清完复扫后建造地基和建筑；范围外及更深地下保留。

清场自上而下按区块进行，每个区块结束后退出循环，下一 tick 重新取区块，避免漏扫。清场和复扫均完成后才开始蓝图施工，房间内部清理先于墙体、灯具和家具写入。每 tick 最多扫描 32768 格、修改 2048 格，时间预算为 6 ms；冷区块通过区块票据等待加载。

进度会保存到世界存档，退出后重进继续施工。每个世界同时只允许一个城镇施工任务，反复点击不会覆盖当前任务。v3/v4 的活动任务重置游标并从完整清场开始。取消后保留已写入部分。已完成的旧城镇不会自动替换，请选一个新位置生成新版。

## 自制建筑材料

共 80 种（原有 24 种，本轮新增 56 种；完整清单见 [东方修仙方块扩展](ORIENTAL_BLOCK_EXPANSION.md)），均可在创造模式“建筑方块”页找到，并可用 `xiuxian:town_*` 或 `xiuxian:xian_*` ID 获取：

| 用途 | 材料与装饰 |
| --- | --- |
| 地面、墙体、梁柱 | 青黛石砖、青石铺地、云纹白玉、素白粉墙、紫檀木板、朱漆柱材 |
| 屋面 | 朱红琉璃瓦、黛青琉璃瓦、鎏金云纹屋脊、卷云鸱吻、彩绘斗拱 |
| 门窗、围栏 | 回纹花窗、雕花白玉栏、鎏金云霞匾 |
| 照明 | 流苏红灯笼、云纹石灯，两者发光等级均为 15 |
| 室内、庭院 | 紫檀书案、紫檀长凳、云纹货柜、经卷书格、云霞屏风、紫檀礼座、青花灵植盆、镇门玉狮 |

装饰使用静态多部件方块模型，水平朝向与碰撞形状同步；花窗和栏杆的空隙可见且不占满碰撞空间。货柜、经卷书格、礼座当前为装饰，不具有库存或坐下交互。此阶段没有新增生存合成配方。

屋檐、桥栏、店铺和大殿已直接使用这些材料，并补入案几、书格、屏风、青花盆和灯笼。原创资源生成器为 `tools/generate_oriental_assets.py`；离线模型预览为 `tools/preview_oriental_assets.py`，输出 `build/oriental-preview/models.png`。预览读取实际模型 JSON 和纹理，不是游戏截图。

## 验证方式

```powershell
.\gradlew.bat build --no-daemon
.\gradlew.bat runGameTestServer '-PgameTestNamespaces=xiuxian_town' --no-daemon
```

GameTest 覆盖高处和边角完整清场、容器清除、范围外和地下保留、保存游标恢复、旧任务切换，以及整座城镇在冷区块上的实际生成、地基、家具、灯具和城门通行。城镇命名空间应实际运行 **2 个**测试；“0 tests”不能当作通过。

新增六类店铺陈设、殿堂礼器、民居花窗、屋脊檐角和庭园灯饰已接入新版生成。新增模型预览：`build/oriental-preview/architecture.png`、`cultivation.png`、`town-life.png`。旧版未完成任务因施工顺序改变而暂停，请取消后重新选址；已完成城镇不自动覆盖。
